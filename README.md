## About Me

I am a Frontend Developer focused on building clean, scalable, and user-centered products.

I enjoy turning product ideas into polished interfaces, from responsive web dashboards to smooth mobile experiences. My work style is practical: ship fast, keep the code readable, and refine details until the experience feels right.

- Building with Next.js, React, TypeScript, Flutter, and modern UI systems.
- Strong in UI architecture, state management, API integration, and interaction polish.
- Learning deeper mobile engineering, 3D web experiences, realtime apps, and performance.
- Interested in products that are useful, beautiful, and maintainable.

## What I Am Learning

### Web Engineering

- Next.js App Router, Server Components, caching, streaming, and revalidation.
- Design systems with Tailwind CSS, shadcn/ui, Radix UI, and reusable component APIs.
- TanStack Query patterns: optimistic updates, query invalidation, pagination, infinite scroll.
- Frontend architecture for dashboards, internal tools, and product workflows.
- Performance, accessibility, responsive UI, and animation details.

### Mobile Engineering

- Flutter feature-first architecture and clean separation between layers.
- GetX routing, bindings, controller lifecycle, and state synchronization.
- Dio interceptors, token refresh, secure storage, and API error mapping.
- Gesture-heavy UI: swipe cards, carousel, bottom navigation, and mobile interaction polish.
- Realtime updates with SignalR-style events and local cache invalidation.

### Creative & 3D Web

- Three.js fundamentals: scene, camera, renderer, materials, lights, and geometry.
- React Three Fiber for declarative 3D interfaces in React.
- Scroll-based animation and immersive product storytelling.
- WebGL performance basics and asset optimization.
